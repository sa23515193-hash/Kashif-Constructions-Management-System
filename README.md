## ⚙️ Installation & Setup

### Prerequisites
- Node.js
- npm
- MongoDB Atlas account
- Git

### 1. Clone Repository

```bash
git clone https://github.com/sa23515193-hash/Kashif-Constructions-Management-System.git
```

### 2. Navigate to Project

```bash
cd Kashif-Constructions-Management-System
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file using `.env.example`.

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secure_secret
MONGODB_DB=kashif_constructions
```

Never upload your actual `.env` file or expose database credentials.

### 5. Start Development Server

```bash
npm run dev
```

### 6. Run Backend Locally

```bash
npx vercel dev
```

### 7. Build for Production

```bash
npm run build
```

## 🌐 Deployment

The application is designed to use a single GitHub repository for frontend and backend source code.

Configure the required environment variables and deployment secrets before enabling production deployment.
